# StudAI: Правила разработки (AI Rules)

Этот файл содержит ключевые архитектурные и технические правила проекта StudAI. Агенты ИИ должны строго следовать этим правилам при написании кода или изменении структуры.

## 1. Технологический стек
*   **Frontend:** React 18+, TypeScript, Tailwind CSS, Vite.
*   **Backend:** Python 3.10+, FastAPI, Pydantic v2.
*   **AI:** Предпочтение GPT-4o или Claude 3.5 Sonnet для сложных задач. Локальное тестирование — Llama 3 (GGUF).

## 2. Архитектурные принципы
*   **Data-First:** Ядром системы является «Карьерный граф». Любые изменения в профиле пользователя должны отражаться в структуре графа.
*   **API-Centric:** Фронтенд общается с бэкендом только через типизированные API-эндпоинты FastAPI.
*   **Security:** Никаких секретов в коде. Использовать `.env` (не коммитить).

## 3. Стандарты кода
*   **Язык:** Документация и комментарии — на русском. Названия переменных, функций, классов — на английском.
*   **Типизация:** Строгий TypeScript (избегать `any`). Модели Pydantic для всех входных/выходных данных на бэкенде.
*   **Компоненты:** Функциональные компоненты React с хуками. Разделение на UI-компоненты (атомарные) и бизнес-экраны.

## 4. Документирование
*   Любое значимое изменение в архитектуре должно быть отражено в `docs/specs/CORE_SPEC.md`.
*   Планы реализации новых фич создаются в `docs/superpowers/plans/`.

## 5. Работа с LLM
*   Промпты для HR-аналитики должны храниться в отдельных конфигурационных файлах или константах на бэкенде.
*   Всегда учитывать стоимость токенов и использовать стриминг ответов для UI, где это возможно.
